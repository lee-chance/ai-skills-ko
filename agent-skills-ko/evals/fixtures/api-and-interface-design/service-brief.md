# URL 단축 서비스 브리프

이 서비스에는 짧은 URL을 만들고, 슬러그를 찾고, 모은 클릭 통계를 읽는 공개 연산이 필요합니다. 클라이언트에는 브라우저 확장과 모바일 앱이 있으므로, 계약은 하위 호환을 유지해야 합니다.

알려진 제약 조건:

- 목적지 URL은 신뢰할 수 없는 사용자가 넣습니다.
- 슬러그는 URL에 안전한 문자 6자에서 12자입니다.
- 없는 슬러그와 만료된 슬러그는 운영자가 구분할 수 있어야 하지만, 공개 API는 내부 저장 세부 정보를 드러내면 안 됩니다.
- 통계는 최대 1분까지 늦어질 수 있습니다.

아직 정하지 않은 것:

- 호출자가 맞춤 슬러그를 요청할 수 있는지.
- 링크가 기본적으로 만료되는지.
- 통계에 인증이 필요한지.
