# 고객 식별자 마이그레이션

계획: 한 번의 유지보수 창에서 정수 고객 ID를 UUID로 바꿉니다.

1. 쓰기를 막습니다.
2. `ALTER TABLE customers DROP COLUMN id CASCADE`를 실행합니다.
3. UUID `id` 열을 추가하고 값을 채웁니다.
4. 15분 뒤에 쓰기를 다시 켭니다.

작성자가 한 주장:

- 모든 외래 키는 자동으로 다시 만들어집니다.
- 테이블 행은 100만 개 미만입니다.
- 작업은 유지보수 창 안에 끝납니다.
- 어젯밤 백업이면 롤백 대비로 충분합니다.
- 어떤 외부 시스템도 정수 식별자를 저장하지 않습니다.

리허설, 행 수, 의존성 목록, 복원 소요 시간, 롤백
테스트는 첨부되어 있지 않습니다.
