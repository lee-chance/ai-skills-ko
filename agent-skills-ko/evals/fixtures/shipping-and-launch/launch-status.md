# 체크아웃 출시 상태: 내일

- 단위 테스트: 녹색.
- 엔드투엔드 체크아웃 테스트: 결제 확인 타임아웃으로 실패.
- 스테이징 스모크 테스트: 마지막 결제 제공자 변경 이후 실행하지 않음.
- 프로덕션 대시보드: 요청률과 지연 시간은 있음. 결제 실패 알림과
  중복 청구 알림은 없음.
- 피처 플래그: checkout v2는 배포 없이 끌 수 있음.
- 롤백 담당자와 명령: 문서화되지 않음.
- 데이터베이스 변경: 추가되는 nullable 열. 마이그레이션은 스테이징에서 테스트함.
- 지원팀과 온콜은 출시 런북을 받지 않음.
