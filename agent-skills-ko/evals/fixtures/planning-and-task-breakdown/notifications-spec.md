# 알림 스펙

사용자는 작업이 할당되거나 기한이 지났을 때 이메일 알림을 받도록 선택할 수 있습니다. 환경설정은 사용자마다 저장되며 기본값은 꺼짐입니다. 할당
이벤트는 이미 있습니다. 기한 초과 감지는 15분마다 실행됩니다.

요구사항:

- 경계 검증이 있는 환경설정 조회/수정 엔드포인트를 추가합니다.
- 할당 흐름과 기한 초과 흐름에서 알림 잡을 발행합니다.
- 사용자, 작업, 이벤트 유형, 이벤트 버전으로 잡을 중복 제거합니다.
- 기존 제공자 어댑터로 이메일을 보냅니다.
- 메시지 본문은 저장하지 않고 전달 상태만 기록합니다.
- 보내는 경로에 피처 플래그를 답니다. 꺼짐이 안전한 기본값으로 남습니다.

검증에는 환경설정 API 테스트, 잡 중복 제거 테스트,
제공자 어댑터 통합 테스트, 엔드투엔드 할당 시나리오 하나가 포함되어야 합니다.
SMS, 푸시 알림, 알림 이력 UI는 범위 밖입니다.
