# 사용량 기반 청구 브리프

이 제품은 현재 매달 정액 하나를 청구합니다. 리더십은 다음 분기에 사용량
기반 청구를 원하지만, "사용량"은 아직 정의되지 않았습니다. 후보 미터는
API 요청, 처리된 레코드, 성공한 잡입니다.

알려진 제약 조건:

- 기존 고객에게는 마이그레이션 경로가 필요합니다.
- 청구 이벤트는 감사할 수 있고 멱등이어야 합니다.
- 늦게 도착하는 이벤트는 최대 7일까지 있습니다.
- 재무는 청구서 대사를 요구합니다.

아직 모르는 것에는 가격 구간, 무료 허용량, 미터 소유권, 정정
규칙, 고객에게 보이는 사용량, 지역별 세금 처리가 있습니다. 스펙을 작성하고
이 결정들을 드러내세요. 가정으로 구현하지 마세요.
