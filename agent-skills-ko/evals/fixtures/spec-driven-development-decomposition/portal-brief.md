# 고객 포털: 제품 브리프

리더십은 셀프서비스 고객 포털을 하나의 이니셔티브로 출시하기를 원합니다. 위에서
내려온 요청은 다음과 같습니다.

- 고객은 이메일/비밀번호 또는 회사 SSO로 로그인하고, 자신의 계정과 팀원을 관리합니다.
- 고객은 요금제를 고르고 결제 정보를 입력하며 월별 청구서를 받습니다. 요금제 변경은 일할 계산합니다.
- 고객은 청구서, 결제 실패, 팀 초대에 대한 이메일 알림을 받습니다. 엔터프라이즈 고객은 같은 이벤트에 웹훅을 등록할 수 있습니다.
- 관리자는 사용량 대시보드를 봅니다. 좌석 수, API 호출, 월별 지출입니다.

지금까지 모은 제약 조건:

- 청구는 고객이 누구인지 알아야 하므로 계정 데이터에 의존합니다.
- 알림은 청구 이벤트와 계정 이벤트에서 발생합니다.
- 대시보드는 청구 기록과 알림 전달 기록을 읽습니다.
- 네 영역의 리뷰어는 다릅니다. 플랫폼이 계정을 맡고, 재무가
  청구를 맡으며, 그로스가 알림과 대시보드를 맡습니다.
- 각 영역은 그 자체로 출시하고 검증할 수 있어야 합니다. 재무는
  대시보드를 기다리지 않고 청구를 승인하고 싶어 합니다.
