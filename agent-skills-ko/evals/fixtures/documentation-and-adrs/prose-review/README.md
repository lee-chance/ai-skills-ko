# Batch Queue

Batch Queue는 배치 처리의 힘을 매끄럽게 열어 주는, 혁신적이고 엔터프라이즈급인 솔루션입니다. 오늘날 빠르게 돌아가는 환경에서, 이 견고한 큐가 운영자로 하여금 작업을 다음 단계로 끌어올리게 해 준다는 점을 밝혀 두는 것이 중요합니다.

## 배치 제출

```sh
queuectl submit jobs.json --max-batch-size 50
```

배치 하나에는 작업이 최대 50개입니다. 큐 항목은 72시간 뒤에 만료됩니다. 실패한
작업은 최대 세 번까지 재시도됩니다.

운영자는 재시도 뒤에도 실패하는 작업을 검토합니다. 큐 상태는
메모리에 있으며, 프로세스가 다시 시작되면 남지 않습니다.

이것은 작업이 하나도 사라지지 않음을 보장하며, 운영자는 큐를 지켜볼 필요가 전혀 없다는 뜻입니다.
