# v1 API 목록

- 공개 소비자: 조직 200곳.
- 대체: `/v2/orders`. 프로덕션에서 쓸 수 있지만 아직 발표하지 않았습니다.
- 현재 v1 트래픽: 활성 API 키 173개에서 하루 요청 48,000건.
- 가장 큰 소비자 계약은 호환을 깨는 변경에 90일 전 고지를 요구합니다.
- 기존 텔레메트리는 API 키, 라우트, 상태, 응답 지연 시간을 기록합니다.
- 지원팀은 소비자 188곳에 직접 연락할 수 있습니다. 12곳은 리셀러가 관리하는 계정을 씁니다.
- v1에는 현재 응답 지원 종료 헤더도, 마이그레이션 가이드도 없습니다.
