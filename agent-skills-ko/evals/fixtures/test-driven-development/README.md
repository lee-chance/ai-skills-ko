# split-payment

`n`명의 참가자에게 금액을 나누되, 센트를 잃거나 만들어 내지 않는
유틸리티입니다. 금액은 처음부터 끝까지 정수 센트입니다. 이
라이브러리는 부동 소수점을 건드리지 않습니다.

## API

`splitCents(totalCents, n)`은 정수 센트 금액 `n`개의 배열을 반환합니다.
`totalCents`는 0 이상의 정수이고, `n`은 양의 정수입니다.

## 불변 조건

모든 결과는 모든 입력에 대해 두 불변 조건을 모두 만족해야 합니다.

1. **정확성.** 몫을 합하면 정확히 `totalCents`가 됩니다. 돈은
   사라지거나 새로 생기지 않습니다.
2. **공정성.** 어떤 두 몫도 1센트보다 더 차이 나지 않습니다. 총액이
   나누어떨어지지 않으면, 남은 센트는 앞쪽 몫에 1센트씩 갑니다.

예를 들어 `splitCents(100, 7)`은 `[15, 15, 14, 14, 14, 14, 14]`입니다.
