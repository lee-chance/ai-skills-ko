# 메뉴 컴포넌트 규약

- 프레임워크: TypeScript를 쓰는 React.
- 스타일: 기존 `menu-*` 유틸리티 클래스. 스타일링 의존성을 추가하지 마세요.
- 공개 컴포넌트는 `className`을 받고 DOM ref를 전달합니다.
- 컴포넌트는 키보드만 쓰는 사람과 스크린 리더 사용자를 지원해야 합니다.
- 메뉴가 닫히면 포커스는 트리거로 돌아갑니다.
- Escape는 메뉴를 닫고, 화살표 키는 사용할 수 있는 항목 사이를 이동합니다.

새 드롭다운은 트리거 라벨과 액션 배열을 드러내야 합니다. 비활성화된
액션은 그대로 보이지만, 포커스를 받거나 실행될 수 없습니다.
