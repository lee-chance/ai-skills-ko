# 감사 기록이 있는 시크릿 교체

이 Python/SQLite 프로젝트는 표준 라이브러리 밖의 의존성이 없습니다.

전체 스위트는 `python3 -m unittest`로 실행하세요.

`replace_secret`은 교체 값과 그에 맞는 감사 기록을
함께 저장해야 합니다. 실패한 작업 뒤에 데이터베이스를 다시 열면 이전
값이 있고 새 감사 기록은 없어야 합니다. 성공한 작업은 둘 다 저장해야 합니다.
`after_write` 콜백은 시크릿을 쓴 뒤, 감사를 쓰기 전의 결함 주입 경계입니다. 구현을 고칠 때도 그 자리에 두세요.
