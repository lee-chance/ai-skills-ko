agent-skills:code-simplification 스킬을 호출하세요.

동작을 그대로 유지하면서, 최근 바뀐 코드(또는 지정된 범위)를 단순화하세요.

1. CLAUDE.md를 읽고 프로젝트 관례를 살펴보세요
2. 대상 코드를 식별하세요. 더 넓은 범위가 지정되지 않았다면 최근 변경입니다
3. 손대기 전에 코드의 목적, 호출자, 엣지 케이스, 테스트 커버리지를 이해하세요
4. 단순화할 곳을 찾으세요.
   - 깊은 중첩 → 가드 절 또는 추출한 헬퍼
   - 긴 함수 → 책임별로 분리
   - 중첩된 삼항 연산자 → if/else 또는 switch
   - 일반적인 이름 → 서술적인 이름
   - 중복된 로직 → 공유 함수
   - 죽은 코드 → 확인한 뒤 제거
5. 단순화를 하나씩 적용하세요. 바꿀 때마다 테스트를 실행하세요
6. 모든 테스트가 통과하고, 빌드가 성공하며, diff가 깔끔한지 확인하세요

단순화 뒤에 테스트가 실패하면 그 변경을 되돌리고 다시 검토하세요. 결과는 `code-review-and-quality`로 리뷰하세요.
