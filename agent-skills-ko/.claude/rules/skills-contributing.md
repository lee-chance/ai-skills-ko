# 스킬 추가 또는 변경

이 저장소는 개발 수명주기의 대부분을 이미 다루므로, 새 스킬 아이디어는 대부분 기존 스킬이나 열린 풀 리퀘스트와 겹칩니다. 새 `skills/<name>/` 디렉터리를 만들거나 기존 스킬을 크게 고치기 전에 다음을 하세요.

- [CONTRIBUTING.md](../../CONTRIBUTING.md#before-proposing-a-new-skill)의 사전 점검을 실행하세요. 카탈로그를 검색하고, 열린 풀 리퀘스트를 확인하며(`gh pr list --state open`), 그 공백이 필요한 이유를 밝히세요.
- 거의 같은 스킬을 새로 추가하기보다 기존 스킬을 확장하세요. 아이디어가 기존 스킬과 겹치면 새 디렉터리를 추가하지 말고 그 스킬을 수정하세요.
- `SKILL.md`는 [docs/skill-anatomy.md](../../docs/skill-anatomy.md)의 범위 안에 두세요. 스킬끼리 내용을 중복하지 말고, 다른 스킬을 참조하세요.

CONTRIBUTING.md가 전체 워크플로우의 단일 기준입니다. 이 규칙은 그 체크리스트를 다시 적지 않고 그 문서를 가리킵니다.
