# 제품 연구

이 예시들은 알아볼 수 있는 제품 인터페이스를 재현합니다. 브리프에 제품 충실도, 더 빽빽한 콘텐츠, 네이티브 크롬, 특정 상호작용이 필요할 때 사용하세요. 플레이그라운드의 **실제 제품** 아래에 있습니다. 일러스트이며, 동작하는 클라이언트가 아니고, 보여 주는 제품과 제휴하지 않습니다.

| 제품 | 출처 | 초점 |
| --- | --- | --- |
| Figma | `examples/figma/` | 캔버스 객체, 속성, 댓글 |
| Linear | `examples/linear/` | 커맨드 메뉴, 이슈 맥락, 할당 |
| Slack | `examples/slack/` | 반응, 메시지 레이아웃, 스레드 답장 |
| Raycast | `examples/raycast/` | 키보드 검색과 클립보드 탐색 |
| Finder | `examples/finder/` | Quick Look, 파일 선택, 드래그 |
| 유리가 있는 Finder | `examples/finder-glass/` | 반투명 창 표면 |
| Spotify | `examples/spotify/` | 라이브러리와 미디어 컨트롤 |
| Notion | `examples/notion/` | 문서 블록과 편집 컨트롤 |
| Gmail | `examples/gmail/` | 받은편지함과 메시지 액션 |
| Google Calendar | `examples/google-calendar/` | 이벤트와 캘린더 뷰 |
| Google Docs | `examples/google-docs/` | 문서 편집과 협업 |
| PowerPoint | `examples/powerpoint/` | 슬라이드 편집 |
| Excel | `examples/excel/` | 셀, 선택, 계산 |
| Wikipedia | `examples/wikipedia/` | 검색 제안과 문서 탐색 |
| Telegram | `examples/telegram/` | 휴대폰 대화와 메시지 도착 |
| iMessage | `examples/imessage/` | 네이티브 작성기와 전달 피드백 |

일부 연구는 플레이그라운드가 설치하는 `lucide-react`를 임포트합니다. 호스트로 복사할 때는 로컬 CSS와 에셋을 유지하고 해당 아이콘 의존성을 설치하거나, 아이콘을 호스트 세트로 바꾸세요. 키트 자체에는 React, react-dom, 그리고 `Icon`을 위한 lucide-react가 필요합니다. 제품 이름, 마크, 이미지는 `NOTICE.md`가 다룹니다.

소스를 열고, 빌리기 전에 의도한 너비에서 보세요. 알아볼 수 있는 인터페이스도 약한 크롭, 리셋, 전환을 가질 수 있으니 새 장면과 같은 리허설을 하세요. 이 목록에 있다는 것은 리뷰가 아닙니다.
