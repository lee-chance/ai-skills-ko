# 커서 모프

커서는 스스로 스타일을 고릅니다. real, large, circle, arrow, 그리고 다시 real입니다. 다섯 번째인 `touch`는 휴대폰용입니다.
각 실루엣은 둘레 72개 점으로 다시 샘플링되고, 같은 감쇠 스프링(감쇠비 0.62, 각주파수 15)으로 모프됩니다. 색과
획 두께는 제한되고, 지오메트리는 오버슈트할 수 있습니다. 리타겟팅은
현재 윤곽에서 시작하고, 언마운트하면 대기 중인 프레임이 취소됩니다.

포털은 위치와 누르기 피드백을 키트 커서에 태웁니다. 상태는
Stage에 있고, 형태는 두 번째 선택 스타일 상태를 유지하지 않습니다. 모션 감소는
바로 정착합니다. 컴팩트 레이아웃은 358px 스테이지 안의 318px 컨트롤을 쓰며,
14px 레이블을 유지합니다.

커서가 *정체성*을 바꿀 때 이것을 사용하세요. 일반적인 pointer/hand/ibeam 변경은
키트의 커서 종류를 사용해야 합니다.
