# Skills

이 저장소에는 AI 코딩 에이전트를 위한 독립적인 스킬이 포함되어 있습니다. 각 스킬의
지침, 참조 자료, 예시, 지원 도구를 해당 폴더에 함께 보관하세요.

## 빠른 시작

Node 20.19 이상을 사용하는 Stageshow 예시 플레이그라운드:

```sh
cd stageshow
npm install
npm run dev
```

Vite가 출력하는 로컬 URL을 여세요. 나머지는 스킬의 README에 있습니다.

## 스택 및 검사

Stageshow는 React, TypeScript, CSS를 사용합니다. 코드를 변경한 후 해당 폴더에서
`npm run typecheck`와 `npm run check:css`를 실행하세요. 예시나 모션을 변경할 때는
리허설 가이드를 따르세요. 같은 워크스페이스의 개발 서버가 실행 중일 때는
프로덕션 빌드를 실행하지 마세요.

## 브랜치 워크플로우

변경사항에는 기능 또는 수정 브랜치를 사용하세요. 관련 없는 스킬과 실험은
분리하세요. 생성된 녹화, 종속성, 자격 증명 또는 머신별 경로를 커밋에 포함하지 마세요.
설치된 폴더가 독립적으로 작동할 수 있도록 참조 자료를 각 스킬에 로컬로 유지하세요.
