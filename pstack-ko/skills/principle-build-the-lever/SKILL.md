# Build the Lever (레버 빌드)

작업이 사소하지 않다면, 손으로 하는 대신 그것을 수행하는 도구(codemod, script, generator 또는 재실행 가능한 체크)를 빌드하세요. 기준은 반복이 아니라 사소함입니다. 한눈에 보이는 명백한 편집 몇 개일 때만 도구를 건너뛰세요.

- 첫 번째 단위는 손으로 수행한 다음, 도구를 빌드하고 그 단위에 재실행하여 증명하세요. 재실행해도 안전하게 만드세요.
- 결정론적 도구가 팬아웃을 이깁니다. 팬아웃할 때는 레시피, 검증 계약, 펜스를 위임자가 읽을 수 있되 편집할 수는 없는 하나의 스킬로 작성하세요.
- 이 원칙을 적용하면 파일이 생성됩니다. diff에 script, codemod, generator 또는 위임자 스킬이 없다면 적용하지 않은 것입니다. 작업이 세션보다 오래 지속된다면 커밋하세요.
- 작업을 수행하거나 증명하는 가장 작은 스크립트를 빌드하세요. 프레임워크는 안 됩니다.
