# Foundational Thinking (기초적 사고)

로직을 작성하기 전에 데이터 형태를 올바르게 하세요. 핵심 타입을 일찍 정의하고, 모든 액세스 패턴을 추적하고, 주요 경로와 일치하는 구조를 선택하세요. 모든 라인이 아니라 구조를 DRY하세요.

액터 간에 상태를 공유하기 전에, 다른 액터가 이것을 동시에 수정하면 무슨 일이 일어나는지 질문하세요. 답이 "아무 일도 없다"가 아니라면 격리하세요.

스캐폴드를 먼저 하세요. 모든 이후 단계를 돕는 것(CI, 테스트, 공유 타입)을 먼저 하되, 데드 코드를 제거한 뒤에 하세요. 커밋은 작고 단일 목적으로 유지하세요.
