# Type System Discipline (타입 시스템 규율)

컴파일러가 불가능한 상태, 일치하지 않는 프리미티브, 처리되지 않은 변형을 거부하도록 만드세요.

- **의미론적 프리미티브를 브랜드하세요.** 두 인수가 프리미티브 타입을 공유하지만 다른 것을 의미한다면, 각각에 자체 타입을 주세요. 생성 시 한 번 검증하세요.
- **외부 데이터는 파싱될 때까지 타입이 없습니다.** JSON, RPC 페이로드, CLI 인수, 설정, 환경 변수, 데이터베이스 행은 경계에서 타입이 있는 모델을 반환하는 파싱 함수를 거칩니다.
- **권위있는 스키마에서 타입을 파생하세요.** 스키마 파일이 형태를 소유할 때는, 병렬 타입을 손으로 만드는 대신 그것에서 타입을 파생하세요.

TypeScript 구문은 **typescript-best-practices** 스킬을 참조하세요.
