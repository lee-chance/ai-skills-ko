# Sequence work into verifiable units (작업을 검증 가능한 단위로 시퀀싱)

작업을 각각 확인할 수 있는 상태로 끝나는 작은 단위로 정렬하고, 현재 단위가 green이 되기 전에는 다음으로 넘어가지 마세요.

스윕, 마이그레이션 또는 비슷한 편집의 연속에서 각 단위는 하나의 브래킷입니다: 정상 상태 확인, 변경 하나, 체크 실행, 진행. 도구가 편집을 수행하더라도 단위별 체크를 실행하세요.

작업을 증명하는 순서로 전달하세요: 실패하는 테스트가 먼저, 그다음 수정. 재구성 전에 제거. 처리 전에 기준선. 각 커밋은 독립적으로 반영됩니다.
