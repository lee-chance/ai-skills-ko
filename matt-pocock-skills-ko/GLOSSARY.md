# 용어집

이 저장소에서 사용되는 주요 용어들입니다.

## 스킬 관련

- **User-invoked skill (사용자 호출 스킬)**: `/grill-me` 같이 사용자가 직접 입력해야만 호출되는 스킬
- **Model-invoked skill (모델 호출 스킬)**: 에이전트가 필요시 자동으로 호출할 수 있는 스킬
- **Promoted buckets (홍보된 버킷)**: `engineering/`과 `productivity/` 폴더 - 공식적으로 제공되는 스킬들
- **Grilling (그릴링)**: 사용자에게 상세한 질문을 하여 요구사항을 명확히 하는 인터뷰 프로세스

## 엔지니어링 용어

- **Tracer bullet (추적탄)**: 전체 시스템을 관통하는 최소 기능 구현
- **Red-green-refactor**: 테스트 주도 개발의 사이클 (실패하는 테스트 작성 → 통과시키기 → 리팩토링)
- **Deepening (깊게 만들기)**: 작은 인터페이스 뒤에 많은 기능을 숨겨 모듈을 단순화하는 것
- **ADR (Architecture Decision Record)**: 아키텍처 결정 기록
- **Domain model (도메인 모델)**: 프로젝트의 개념과 용어를 정의한 공유 언어

## 워크플로우 용어

- **Handoff (핸드오프)**: 다른 에이전트나 사람에게 작업을 넘기기 위한 문서
- **Spec (스펙)**: 구현할 기능에 대한 상세한 명세
- **Triage (트리아지)**: 이슈를 분류하고 우선순위를 정하는 프로세스
