## 번역 가이드

번역은 이 저장소 루트의 `TRANSLATION_GUIDE.md`를 따릅니다:
- 코드, 명령어, 파일 경로는 변경하지 않음
- YAML frontmatter의 `name`은 그대로, `description`은 번역
- 슬래시 커맨드 이름은 그대로 (`/grill-me`, `/tdd` 등)
- 기술 용어는 일관된 한국어 사용 (용어집 참조)

## 향후 작업

나머지 파일들을 번역하려면:
1. `TRANSLATION_GUIDE.md`를 참조하여 번역 규칙 확인
2. 기존 번역된 파일들의 스타일을 참고
3. 각 `SKILL.md` 파일을 번역
4. 문서 파일들 (`docs/`, `.agents/`) 번역
5. 이 `SOURCE.md`의 번역 상태 업데이트
