# Credits

**Summary** 섹션의 시각 자료 메뉴(의사 코드, 호출 트리, 컴포넌트 트리, 파일 트리, Mermaid, diff)와 배치 가이드는 [Dex Horthy](https://github.com/dexhorthy)의 [`show-me`](https://github.com/humanlayer/humanlayer) 스킬에서 왔으며, 거의 그대로 재현되고 라이브 대화 대신 diff를 목표로 합니다. `pr`은 스킬로서 `show-me`에 의존하지 않습니다(이 저장소의 일부가 아니며, 하드 의존성은 독립 설치를 깨뜨릴 것입니다). 따라서 내용이 가리켜지는 대신 복사되었습니다; 이 파일은 의존성이 달리 운반했을 귀속입니다.
